РУССКАЯ РАСКЛАДКА ПО УМОЛЧАНИЮ — ИНСТРУКЦИЯ
Calculate Linux Desktop Cinnamon и другие системы с рабочим столом Cinnamon
(Та же инструкция со скриншотами: ИНСТРУКЦИЯ.html)

Пароль, sudo и интернет НЕ нужны. Около минуты на один компьютер.

КОРОТКО: скопировать папку -> «Установить» -> «Сделать доверенной»
         -> «ГОТОВО!» -> перезагрузить.

----------------------------------------------------------------
ШАГ 1. Скопируйте папку на рабочий стол
  Войдите в систему (обычно пользователем guest).
  Вставьте флешку, откройте её и перетащите папку
  CLDC-Russian-Default-USB на рабочий стол.
  Запускайте копию с рабочего стола, а не с флешки.

ШАГ 2. Дважды щёлкните «Установить»
  Откройте папку на рабочем столе и дважды щёлкните «Установить.desktop».

ШАГ 3. Нажмите «Сделать доверенной»
  Появится окно «Сомнительная кнопка запуска». Это обычный вопрос
  о ярлыках с флешки. Нажмите «Сделать доверенной» (один раз).
  «Запустить всё равно» тоже сработает, но вопрос появится снова.

ШАГ 4. Значок сменится на клавиатуру
  Ярлык станет называться «Установить» и получит значок клавиатуры.
  Если окно установки не открылось само, дважды щёлкните его ещё раз.

ШАГ 5. Дождитесь надписи «ГОТОВО!»
  Зелёная рамка «ГОТОВО! Установка выполнена успешно» — всё хорошо.
  На панели появится индикатор «ru». Нажмите Enter, окно закроется.
  Красная рамка «ОШИБКА» — окно не закроется само: прочитайте причину
  (см. «ЕСЛИ ЧТО-ТО НЕ ТАК»).

ШАГ 6. Перезагрузите компьютер
  Меню -> Выход -> Перезагрузить. Войдите тем же пользователем.
  Без переключения раскладки откройте Chrome или LibreOffice и напечатайте
  что-нибудь — должны появиться русские буквы.
  Super+Пробел (клавиша с логотипом + пробел) переключает на английский.

ШАГ 7. Откройте «Проверить установку»
  В той же папке дважды щёлкните «Проверить установку»
  (в первый раз тоже «Сделать доверенной»).
  Должно быть: «ВСЁ В ПОРЯДКЕ». Компьютер готов.

----------------------------------------------------------------
ЕСЛИ ДВОЙНОЙ ЩЕЛЧОК НЕ ЗАПУСКАЕТ УСТАНОВКУ
(открывается текст файла или ничего не происходит)

Способ А — разрешить запуск одного файла:
  1. Правый щелчок по «Установить» -> «Свойства».
  2. Вкладка «Права».
  3. Поставьте галочку «Разрешить выполнение файла как программы».
  4. Закройте окно и снова дважды щёлкните «Установить».

Способ Б — через терминал (всегда работает):
  1. Откройте папку CLDC-Russian-Default-USB на рабочем столе.
  2. Правый щелчок по пустому месту в папке -> «Открыть в терминале».
  3. Напечатайте (латиницей) и нажмите Enter:
        bash app/usb-launcher.sh install
     Проверка установки:
        bash app/usb-launcher.sh check

Системную защиту отключать не нужно.

----------------------------------------------------------------
ЕСЛИ ЧТО-ТО НЕ ТАК

«запущено от имени root»
  -> Выйдите и войдите обычным пользователем (например, guest),
     запустите снова.

«не найден файл программы»
  -> Папка скопирована не полностью. Скопируйте всю папку вместе с папкой app.

«ключ ... недоступен для записи»
  -> Настройку заблокировал администратор. Обратитесь к администратору.

После перезагрузки «Проверить установку» пишет «НЕ УСТАНОВЛЕНО»
  -> Профиль пользователя очищается при каждом выходе. Установка
     в профиль не сохраняется — обратитесь к администратору.

Отчёт последнего запуска: ~/.local/state/cldc-russian-default/
  (файлы usb-install-report.txt и usb-check-report.txt)

----------------------------------------------------------------
КАК УДАЛИТЬ (вернуть всё как было)
  В терминале:
     ~/.local/bin/cldc-russian-default uninstall --restore

Не открывайте и не сохраняйте файлы из этой папки в Блокноте Windows.
